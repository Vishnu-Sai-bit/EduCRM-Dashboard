Enterprise Admissions Intelligence & Operations Command Center.

- **Primary Dashboard File**: [`EduCRM_Live_Dashboard.html`](EduCRM_Live_Dashboard.html)

### Key Capabilities
- **Executive Command Center**: High-level institutional operations, 72,738 lead pipeline metrics, conversion velocity, and tuition realization.
- **Leads Intelligence Engine**: Full CRM lifecycle tracking (New Leads, Contacted, Interested, Free Demo Attended, Enrolled).
- **Counsellors Productivity Hub**: 
  - 20-Min Lead Response SLA compliance monitoring.
  - Combined New Leads & Follow-ups Calling Cadence Line Chart (stock-style intraday pacing & heartbeat gaps).
  - Automated Round-Robin Lead Allotment Engine (sequential 1-to-5 cyclical routing with capacity auto-balancing).
  - Admin Call Discipline & "Time-Passing" (Slacking) Auditor.
- **Courses & Batches Intelligence**: Program popularity, realization, and batch schedules.
- **Admissions Velocity & Conversions**: Lead-to-admit conversion pathways.
- **Finance & Tuition Realization**: Fee collection health and revenue realization.
- **Auditing & Executive Reporting**: Performance scorecards and telecalling analytics.

### How to Run Locally
1. Download [`EduCRM_Live_Dashboard.html`](EduCRM_Live_Dashboard.html).
2. Double-click the file to open it in any web browser (Chrome, Edge, Firefox, Safari).
3. No installation, server, or database connection required—100% self-contained.
